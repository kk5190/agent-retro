    What fills your context?

    Everything in the context window is re-read on every turn: it costs tokens, and a fuller window gets compacted sooner and loses detail. This page splits a typical session into what is loaded before you type (the system prompt, tool and MCP listings, skills, CLAUDE.md, start-up hooks) and what your work adds (tool results, skill instructions, replies), item by item.     Which extensions earn their place?

    Plugins, skills, MCP servers and hooks are listed to the model at the start of every session, whether you use them or not. Each table compares what was loaded with what was used, and what each one costs. Unused means listed but never used; rarely used means used in under 10% of the sessions it was listed in.
