        Which extensions earn their place?

        Plugins, skills, MCP servers and hooks are listed to the model at the start of every session, whether you use them or not. Each table compares what was loaded with what was used, and what each one costs. Unused means listed but never used; rarely used means used in under 10% of the sessions it was listed in.

        Plugins

        A plugin bundles skills, MCP servers and commands. Listing cost is what its skill descriptions add to every session.

        Skills

        Uses count a Skill call and the load it triggers once. “Per load” is the context a skill adds each time it is used; the listing cost is paid every session.

        MCP servers

        Calls, failures and how much output each server puts into the context. Source says where it is configured; built-in servers come with the app.

        Hooks

        Scripts that run on events. Anything a hook prints goes into the context.

        Subagents

        Helper agents a session starts. Cost is only logged per session, so it is not split out here.

        Slash commands

        Commands you typed, including plugin commands.

        How do you prompt?

        Your prompts only, not the agent's replies, checked against common prompt-engineering practices. Detection is by pattern: it sees whether a practice is there (a file path, an example, a stated goal), not how well it was done. Where there are enough sessions, each practice is compared with how those sessions went.
